划词解释 2.5.0 更新说明

这次只处理实际使用中遇到的问题：

1. 搜索框、输入框中的选中文字现在可以触发翻译按钮。
2. B 站评论区等会拦截鼠标事件的网页现在更容易稳定触发。
3. 日语、韩语和其他非中文语言也能触发；非拉丁文字只显示中文解释按钮。
4. AI 会先判断语言和拼写。明显拼错时会提示可能的正确写法；不确定时不会强行猜。
5. 生词本会在备份中保留删除记录。一个账号删除后导出，再导入另一个账号，可同步删除旧词；删除后重新收藏的新记录不会被旧删除记录误删。
6. OCR 首次识别失败或卡住时会重置识别引擎并自动重试一次；窄而长的单行文字改用更适合的识别方式。

更新方法（尽量保留原设置和生词本）：

1. 先在旧版生词本中导出一次 JSON 备份，并记下 DeepSeek API Key。
2. 保持原插件文件夹的位置和名称不变。
3. 用新版 word-explainer-extension 文件夹内的文件覆盖原文件。
4. 打开 chrome://extensions，找到“划词解释 · Word Explainer”，点击“重新加载”。
5. 刷新已经打开的 B 站或其他网页后再测试。

说明：

- 手机版 Chrome 不能直接安装这份电脑扩展。
- Chrome 内置页面、Chrome 网上应用店、其他扩展页面，以及未获文件访问权限的本地文件，仍可能禁止区域 OCR 或内容脚本运行；这是浏览器限制。
- OCR 目前只内置英文识别模型。它可以把图片中的英文识别成文字，再交给 AI 判断拼写；日语和韩语 OCR 暂不支持。
